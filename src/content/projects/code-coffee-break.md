## A publication that can sit still

This site generates its articles and project pages at build time. The interactive calculator runs locally in the browser. There is no database, authentication service, or continuously running application server.

## The useful constraint

Publishing means editing a Markdown file and building the site. An idea can stay in `notes/ideas/` until there is something worthwhile to explain. Draft and future-dated articles are excluded from public routes, RSS, and topic listings.

## What comes next

Original educational articles use fictional examples and explain their sources. A guest writing workflow can join once there is a real submission destination. More tools can join when an actual problem justifies them. A repository link will be added when a public repository is available.
